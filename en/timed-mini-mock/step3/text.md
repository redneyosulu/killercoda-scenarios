# Weighted review

A mock without review is entertainment. Write `~/miss-log.txt`: one block per fault with its domain (workloads, networking, architecture), its class (knowledge, method, time), and exactly one drill line starting with `drill:` that would prevent its repeat. Name the single domain your next session targets, with the weighted arithmetic shown.

CHECK verifies the log maps faults to domains with a drill per fault. The thinking is the exercise; the file is only its record.
