# kubectl Speed Kit for Exam Day

**Environment.** Kubernetes 1-node (Killercoda), about 25 minutes.

## What you will do

- Open a free browser cluster and confirm node status
- Create, expose and scale a workload with imperative commands only
- Save an alias plus dry-run template that survives the session

All work happens in `/tmp/ck-m00-01`. Keep one session note at `/tmp/ck-m00-01/session-note.txt`; the CHECK scripts read it.

_Wait until the terminal prints `Environment ready` before step 1. Setup runs in the background._
