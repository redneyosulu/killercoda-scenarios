# İkinci Çalışta Zararsız Kurulum Betiği Yaz

**Ortam.** Ubuntu 24.04, Yaklaşık 45 dakika.

## Ne yapacaksın

- Tekrarda yakınsayan çok adımlı kurulum betiği yazmak
- Durum karşılaştırmalarıyla ikinci çalışın işlemsizliğini kanıtlamak
- Hiçbir şeyi değiştirmeden raporlayan --check kipi eklemek

_1. adıma geçmeden terminalde `Environment ready` yazısını bekle. Kurulum arka planda çalışır._
