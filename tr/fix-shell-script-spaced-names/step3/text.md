# İki sonucu da test et

Önce bozuk sürümde düşen (bir şeyi test ettiğini kanıtlayan), sonra onarımda geçen; boşluklu isim ve önde tire kapsayan test yaz. Testi betiğin yanında tut.

**İpucu:** broken.sh üzerinde kırılmayı, fixed.sh üzerinde geçmeyi kanıtlayan test.sh dosyasını yaz (boşluklu isim + baştaki tire), sonra yeşil tut.

_Bitirince bu adımı doğrulamak için **CHECK** düğmesine bas._
