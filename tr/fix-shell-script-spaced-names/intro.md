# Boşluklu Dosyaların Bozduğu Kabuk Betiğini Düzelt

**Ortam.** Ubuntu 24.04, Yaklaşık 40 dakika.

## Ne yapacaksın

- Boşluklu dosya adlarıyla kelime bölünme arızasını yeniden üretmek
- Alıntılama, joker ve set -euo pipefail ile onarmak
- Düşüp geçen test ve temiz ShellCheck çalışmasıyla onarımı kanıtlamak

_1. adıma geçmeden terminalde `Environment ready` yazısını bekle. Kurulum arka planda çalışır._
