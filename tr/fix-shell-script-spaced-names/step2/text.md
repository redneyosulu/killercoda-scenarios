# Hasmane isimlere onar

Jokerle yeniden yaz (ayrıştırılmış ls asla), genişlemeleri alıntıla, -- argüman korumaları ekle, set -euo pipefail koy. ShellCheck çalıştır; hataları değil tüm uyarıları temizle.

**İpucu:** fixed.sh dosyasını glob ile (asla ayrıştırılmış ls yok), tırnaklı açılımlar, -- korumaları ve set -euo pipefail ile yaz. shellcheck sıfır uyarı vermeli.

_Bitirince bu adımı doğrulamak için **CHECK** düğmesine bas._
