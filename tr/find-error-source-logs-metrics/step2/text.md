# Satırlarla birleştir

Grafikten örnek veya sivri pencere istek kimliklerini al, tam o satırları çek; ortak alt hatayı bul. Adlandıran satırları alıntıla.

**İpucu:** Sivri pencereden istek kimliklerini al, tam o log satırlarını çek, ortak alt hatayı bul, ikisini de join.txt dosyasına alıntıla.
