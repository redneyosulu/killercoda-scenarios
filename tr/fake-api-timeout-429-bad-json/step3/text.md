# Kötü girdileri test et

Testler /slow (sınırlı toplam süre doğrulanır), /limited (sonunda başarı, tam 3 istek) ve /broken (temiz sıfır-dışı çıkış, çökme yok) kapsamalıdır. Takımı yeşil göster.

**İpucu:** Yeşil takım: önce /reset, sonra /slow sınırlı (<60sn, sıfır-dışı), /limited sonunda başarılı tam 3 vuruşla, /broken temiz sıfır-dışı. Sonuçları suite.txt dosyasına kaydet.

_Bitirince bu adımı doğrulamak için **CHECK** düğmesine bas._
